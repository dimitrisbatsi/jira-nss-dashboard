# 📊 NSS Support Timesheet Dashboard

Αυτή η εφαρμογή παρέχει μια διαδραστική απεικόνιση των Worklogs από το Jira Cloud για την ομάδα NSS Support.

## 🔐 Διαχείριση Ασφάλειας (Secrets)

Για λόγους ασφαλείας, τα ευαίσθητα δεδομένα (Email & API Token) **δεν** περιλαμβάνονται στον κώδικα της εφαρμογής. Αποθηκεύονται στο αρχείο:
`./.streamlit/secrets.toml`

### Σημασία των Secrets
- **Ασφάλεια:** Αποτρέπει τη διαρροή κωδικών σε περίπτωση που ο κώδικας ανέβει σε κάποιο αποθετήριο (π.χ. GitHub/GitLab).
- **Ευελιξία:** Επιτρέπει την αλλαγή στοιχείων πρόσβασης χωρίς την τροποποίηση του πηγαίου κώδικα.

## 🔑 Οδηγίες Δημιουργίας Νέου API Token

Σε περίπτωση που το Token λήξει ή αλλάξει ο διαχειριστής της εφαρμογής, ακολουθήστε τα παρακάτω βήματα:

1.  Συνδεθείτε στο λογαριασμό σας στην Atlassian (Jira).
2.  Μεταβείτε στη σελίδα: [https://id.atlassian.com/manage-profile/security/api-tokens](https://id.atlassian.com/manage-profile/security/api-tokens).
3.  Πατήστε το κουμπί **Create API token**.
4.  Δώστε ένα όνομα (π.χ. `Streamlit-Dashboard-Access`) και πατήστε **Create**.
5.  **Αντιγράψτε αμέσως το Token** (δεν θα εμφανιστεί ξανά).
6.  Ανοίξτε το αρχείο `.streamlit/secrets.toml` στον server.
7.  Αντικαταστήστε την τιμή του `JIRA_TOKEN` με το νέο κλειδί.
8.  Αντικαταστήστε το `JIRA_EMAIL` με το email του κατόχου του νέου Token.
9.  Αποθηκεύστε το αρχείο. Η εφαρμογή θα ενημερωθεί αυτόματα στο επόμενο refresh!

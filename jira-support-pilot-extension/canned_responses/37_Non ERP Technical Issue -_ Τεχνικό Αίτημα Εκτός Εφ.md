# 37. Non ERP Technical Issue -> Τεχνικό Αίτημα Εκτός Εφαρμογής

Σας ενημερώνουμε ότι το περιστατικό/αίτημα που αποστείλατε δεν αφορά τη λειτουργικότητα της εφαρμογής PYLON, αλλά ζήτημα τεχνικής φύσεως που σχετίζεται με την υποδομή (ενδεικτικά: λειτουργικό σύστημα, υπηρεσίες SQL Server, δίκτυο ή λοιπά συστήματα τρίτων).
Για ζητήματα αυτού του τύπου, η διερεύνηση και επίλυση πραγματοποιείται σε επίπεδο υποδομής, αξιοποιώντας την αντίστοιχη τεχνική τεκμηρίωση και τα διαθέσιμα εργαλεία διάγνωσης των κατασκευαστών (ενδεικτικά Microsoft για Windows / SQL Server).

Το Τμήμα Υπηρεσιών PYLON υποστηρίζει αποκλειστικά θέματα που σχετίζονται με τη λειτουργία, τα κυκλώματα και την παραμετροποίηση της εφαρμογής.
Εφόσον προκύψει ζήτημα που επηρεάζει άμεσα την εφαρμογή και συνοδεύεται από τα απαραίτητα τεχνικά στοιχεία, μπορείτε να επανέλθετε με νέο αίτημα ώστε να το εξετάσουμε.
Το συγκεκριμένο περιστατικό/αίτημα, μετά τις σχετικές μεταξύ μας επικοινωνίες, θεωρείται κλειστό.

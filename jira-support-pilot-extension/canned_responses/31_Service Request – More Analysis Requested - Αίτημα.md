# 31. Service Request – More Analysis Requested for Device Manager / EFT POS → Αίτημα υπηρεσίας – απαιτείται ανάλυση για Device Manager / POS (6)

Σας ενημερώνουμε ότι οι απαιτήσεις που αποστείλατε σχετικά με το αίτημα υπηρεσίας, χρήζουν περισσότερης ανάλυσης.

Πιο συγκεκριμένα ενημερώστε μας για τα παρακάτω:
* Έκδοση του Device Manager. Σε περίπτωση που δεν βρίσκεστε στην τελευταία έκδοση παρακαλούμε προχωρήστε σε αναβάθμιση
* Έκδοση της εφαρμογής Pylon. Σε περίπτωση που δεν βρίσκεστε στην τελευταία έκδοση παρακαλούμε προχωρήστε σε αναβάθμιση
* Αν υπάρχει Πάροχος ή ΦΗΜΑΣ, καθώς και ποιος συγκεκριμένα.
* Έκδοση firmware του ΦΗΜΑΣ.
* Ποιος είναι ο NSP και το Μοντέλο του EFT POS;
* Το πιθανό μήνυμα σφάλματος σε μορφή κειμένου.
* Από ποιο κύκλωμα της εφαρμογής έγινε η αποστολή του αιτήματος πληρωμής;
  (πχ Γρήγορη Καταχώρηση Πώλησης, Εμπορικές Κινήσεις, Retail, SFA κτλπ)
* Εάν έχει δημιουργηθεί Logfile, αποστείλετε το log.

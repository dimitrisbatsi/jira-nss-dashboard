# 23. Enhancement temporary evaluation pause → Προσωρινή παύση αξιολόγησης βελτιώσεων 

Αξιότιμε Συνεργάτη, 

Σας ενημερώνουμε, ότι η διαδικασία αξιολόγησης αιτημάτων βελτίωσης της εφαρμογής, παύει προσωρινά ενόψει θερινής περιόδου και καλοκαιρινών αδειών. 
Θα ενημερωθείτε σχετικά με την εξέλιξη της αξιολόγησης του παρόν περιστατικού από τον Σεπτέμβριο, οπότε και ξεκινάνε και πάλι οι αξιολογήσεις. 

Για οποιαδήποτε διευκρίνιση, στη διάθεσή σας.

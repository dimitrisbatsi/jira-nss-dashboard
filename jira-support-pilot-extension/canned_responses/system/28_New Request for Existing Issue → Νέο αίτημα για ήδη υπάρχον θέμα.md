# 28. New Request for Existing Issue → Νέο αίτημα για ήδη υπάρχον θέμα

Παρακαλούμε όπως αποστείλετε εκ νέου το αίτημα σας στην νέα Κεντρική Πλατφόρμα Υποβολής Αιτημάτων.
Ο κωδικός αυτός θα χρησιμοποιείται ως σημείο αναφοράς σε οποιαδήποτε μελλοντική επικοινωνία αφορά το συγκεκριμένο περιστατικό /αίτημα.
Το συγκεκριμένο αίτημα θα κλείσει.

Για περισσότερες διευκρινίσεις και οδηγίες για τη διαδικασία διαχείρισης αιτημάτων μπορείτε να ενημερωθείτε [ΕΔΩ](https://kb.epsilon-singularlogic.eu/pylonflex/diacheirisi-aitimaton-stin-nea-kentriki-platforma-ypovolis-aitimaton/).

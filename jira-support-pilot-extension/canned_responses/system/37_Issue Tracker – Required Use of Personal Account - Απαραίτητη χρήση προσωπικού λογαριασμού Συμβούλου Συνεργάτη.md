# 37. Issue Tracker – Required Use of Personal Account -> Απαραίτητη χρήση προσωπικού λογαριασμού Συμβούλου Συνεργάτη

Καλησπέρα

Θα θέλαμε να σας ενημερώσουμε ότι, σύμφωνα με τις οδηγίες που έχουν κοινοποιηθεί στο newsletter του δικτύου (10/03/2026), η καταχώρηση αιτημάτων στο Issue Tracker θα πρέπει να πραγματοποιείται αποκλειστικά από τον προσωπικό λογαριασμό κάθε χρήστη και όχι μέσω του βασικού διαχειριστικού (πατρικού) email του συνεργάτη.
Για τον λόγο αυτό, παρακαλούμε να προχωρήσετε στη δημιουργία του προσωπικού σας λογαριασμού μέσω του MyAccount, ακολουθώντας τις σχετικές οδηγίες.

Για λόγους ορθής καταγραφής και εξυπηρέτησης, το παρόν αίτημα θα κλείσει.
Παρακαλούμε να το υποβάλετε εκ νέου χρησιμοποιώντας τον προσωπικό σας λογαριασμό.

* Για προσθήκη χρηστών (εφόσον δεν έχει γίνει ήδη) Δείτε οδηγίες [εδώ].
* Για καταχώρηση αιτήματος από Σύμβουλο του Συνεργάτη με τον δικό του λογαριασμό δείτε οδηγίες [εδώ].

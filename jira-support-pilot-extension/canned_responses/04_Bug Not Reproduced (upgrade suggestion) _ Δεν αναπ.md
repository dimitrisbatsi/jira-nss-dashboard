# 4. Bug Not Reproduced (upgrade suggestion) → Δεν αναπαράγεται (πρόταση αναβάθμισης)

Σας ενημερώνουμε το περιστατικό που αποστείλατε δεν μπορεί να αναπαραχθεί στην αναβαθμισμένη, σε τελευταία έκδοση, βάση που αποστείλατε.
Παρακαλείστε να αναβαθμίσετε την βάση στην εγκατάσταση του πελάτη ώστε να παρακαμφθεί το πρόβλημα που παρατηρείται.

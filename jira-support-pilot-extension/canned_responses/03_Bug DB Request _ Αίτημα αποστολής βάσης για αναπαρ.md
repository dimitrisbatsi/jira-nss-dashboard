# 3. Bug DB Request → Αίτημα αποστολής βάσης για αναπαραγωγή σφάλματος

Αξιότιμε Συνεργάτη,

Σας ενημερώνουμε ότι το περιστατικό που αποστείλατε δεν μπορεί να αναπαραχθεί σε τυχαία βάση.
Για την αναπαραγωγή του προβλήματος απαιτείται η βάση στην οποία παρατηρείται το πρόβλημα ώστε να επιτευχθεί η αναπαραγωγή. 

Η εν λόγω βάση πρέπει να συμπιεστεί και να αποσταλεί μέσω [WeTransfer](https://pylon.wetransfer.com/).

* Για λόγους ασφαλείας των δεδομένων της εγκατάστασης θα πρέπει, στην βάση που θα αποστείλετε, να έχετε απενεργοποιήσει όλες τις παραμέτρους που αφορούν στοιχεία σύνδεσης ΑΑΔΕ και στοιχεία Λογιστή, στοιχεία λήψης ΑΦΜ, Voucher, παράμετροι email κτλ.
* Κατά την προσθήκη του αρχείου και πριν την αποστολή του, πρέπει οπωσδήποτε να γράψετε στο Title και στο Message του WeTransfer το λεκτικό **[PYLCOM-XXXXXX] PYLON** και τον τίτλο του περιστατικού, όπου XXXXXX ο αριθμός του περιστατικού που αφορά. 
* Σε περίπτωση που δεν αναγράφεται το παραπάνω λεκτικό, τότε το email με το αρχείο **θα διαγράφεται και δε θα γίνεται δεκτό**.

Με την ολοκλήρωση της αποστολής της βάσης, παρακαλείστε να ενημερώσετε το τμήμα υποστήριξης Pylon με σαφές σενάριο αναπαραγωγής του προβλήματος, την έκδοση του Pylon και του SQL Server, καθώς και να επισυνάψετε τη σύμβαση συγκατάθεσης πρόσβασης στην βάση δεδομένων από τον Πελάτη σας προς την Epsilon Net.

Παρακάτω στο URL θα βρείτε τη σύμβαση συγκατάθεσης GDPR:
[Σύμβαση Διαβίβασης Δεδομένων - Epsilon Support](https://support.epsilonnet.gr/messages.aspx?TopicID=29338325&ForumID=5875)

Για περεταίρω πληροφορίες σχετικά με Ανωνυμοποίηση / Κρυπτογράφηση Βάσης περισσότερες πληροφορίες [εδώ](https://support.epsilonnet.gr/messages.aspx?TopicID=113892).

Τέλος θα θέλαμε να σας ενημερώσουμε ότι σε περίπτωση που προκύψει ότι το σφάλμα δεν οφείλεται στην εφαρμογή θα υπάρξει χρέωση.
Στον χρόνο της Χρεώσιμης Υπηρεσίας εκτός από τον χρόνο αποκατάστασης θα συμπεριληφθεί και ο χρόνος μεταφοράς της βάσης, download και διάγνωσης.
Επιπρόσθετα, σας ενημερώνουμε πως είναι απαραίτητη η αποστολή του εγγράφου συγκατάθεσης ώστε να ξεκινήσει η διαδικασία επεξεργασίας της βάσης δεδομένων.

Ελάχιστος χρόνος χρέωσης δύο (2) ώρες.

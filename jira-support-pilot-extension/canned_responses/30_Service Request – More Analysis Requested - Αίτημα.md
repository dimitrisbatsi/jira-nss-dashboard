# 30. Service Request – More Technical Analysis Requested → Αίτημα υπηρεσίας – απαιτείται τεχνική ανάλυση (7)

Σας ενημερώνουμε ότι σχετικά με το αίτημα που αποστείλατε και την καθυστέρηση που παρατηρείται, απαιτούνται περεταίρω πληροφορίες.

Πιο συγκεκριμένα ενημερώστε μας για τα παρακάτω:
* Server Specifications (CPU, RAM, Σκληρός Δίσκος, Λειτουργικό Σύστημα, .NET Framework)
* SQL Specifications (SQL Server Type, Χωρητικότητα βάσης Pylon)
* Αρχιτεκτονική εγκατάστασης Pylon:
    * Αν ο server είναι φυσικό μηχάνημα ή VirtualMachine
    * Πόσοι clients συνδέονται ταυτόχρονα με τον Server
    * Ταχύτητες δικτύου (download & upload) σε Server και Clients
    * Αν υπάρχει ενεργοποιημένο Compress Data σε όλα τα Workareas
* Εμφανίζει κάποιο σφάλμα για το Poseidon Service στον Event Viewer των Windows;
* Η καθυστέρηση γίνεται μόνο στην εφαρμογή του Pylon ή σε ολόκληρο το μηχάνημα;
* Καθυστερούν όλες οι εφαρμογές του Pylon ή μόνο οι clients; Η ίδια καθυστέρηση αναπαράγεται στο Server;
    * Αν ναι, με Restore της βάσης σε άλλο μηχάνημα συνεχίζει να υπάρχει η ίδια καθυστέρηση;

# 33. Resubmit Request to Correct Project Tickets → Επαναυποβολή αιτήματος στο σωστό project (tickets)

Καλησπέρα σας,

Θα θέλαμε να σας ενημερώσουμε ότι το συγκεκριμένο αίτημα αφορά **Pylon Λογιστική**.
Για τον λόγο αυτό παρακαλούμε όπως υποβάλετε εκ νέου το αίτημα, επιλέγοντας στο πεδίο “Project” την τιμή **“Pylon Accounting”** αντί της τιμής “Pylon Commercial”.

Σε περίπτωση που η τιμή “Pylon Accounting” δεν είναι διαθέσιμη στη φόρμα υποβολής αιτήματος, παρακαλούμε ενημερώστε μας μέσω του παρόντος αιτήματος ώστε να προχωρήσουμε στις απαραίτητες ενέργειες.
Για το υπάρχον αίτημα, και εφόσον η τιμή “Pylon Accounting” είναι διαθέσιμη στο πεδίο “Project”, προχωρήστε στην ακύρωσή του επιλέγοντας στο πεδίο “Κατάσταση” την τιμή “Canceled”.

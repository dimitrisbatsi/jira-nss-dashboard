# 10. Service Request – More Analysis Requested → Αίτημα υπηρεσίας – απαιτείται περισσότερη ανάλυση (5)

Σας ενημερώνουμε ότι οι απαιτήσεις που αποστείλατε, χρήζουν περισσότερης ανάλυσης.

Πιο συγκεκριμένα ενημερώστε μας για τα παρακάτω:
* Αναπαράγεται η συμπεριφορά σε τελευταία έκδοση της εφαρμογής;
* Αναπαράγεται η συμπεριφορά σε δικό σας δοκιμαστικό περιβάλλον;
* Αναπαράγεται η συμπεριφορά σε δικό σας περιβάλλον στο backup της βάσης του πελάτη;

Παρακαλείστε όπως αποστείλετε περισσότερες πληροφορίες για την ανάγκη που απαιτείται να καλύψει η εφαρμογή στον πελάτη.

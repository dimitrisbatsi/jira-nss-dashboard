# 2. Metafora Cloud

Αξιότιμε συνεργάτη,

Κατόπιν των σχετικών μας επικοινωνιών για το αίτημα μεταφοράς της βάσης δεδομένων του πελάτη ........... στο Cloud θα χρειαστούμε τα παρακάτω:

* Backup της βάσης της εφαρμογής. Απαραίτητα να είναι σε MsSQL Server 2016 (13 ή μικρότερη) και έκδοση PYLON 26.01.10 με DB Collation [Greek\_CI\_AS].
* Έντυπο συγκατάθεσης του πελάτη.

Η εν λόγω βάση και το έντυπο συγκατάθεσης πρέπει να συμπιεστούν και να αποσταλούν μέσω WeTransfer (WeTransfer | Send Large Files Fast ). Κατά την προσθήκη των αρχείων πρέπει οπωσδήποτε να γράψετε στο Message τον κωδικό του περιστατικού PYLCOM.

Το έντυπο συγκατάθεσης πελάτη υπάρχει επισυναπτόμενο.

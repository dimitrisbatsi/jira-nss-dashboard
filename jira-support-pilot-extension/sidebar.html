📖 How to generate a Jira API Token? ▶
  1. Go to Atlassian Security Settings.
  2. Log in with your corporate account (e.g., username@epsilonnet.gr).
  3. Click "Create API token".
  4. Label it (e.g., Jira Support Pilot) and click "Create".
  5. Click "Copy" to copy the token.
  6. Paste the token in the input field above and click "Save Settings".
